# 休假獎金統計小本 V0.7.1

修改日期：2026-10-03

## 執行

需要 Python 3.10 以上及 Tkinter，無第三方套件需求。
Windows 可執行 LeaveBonusTracker_V0_7_1.pyw；需要終端錯誤訊息時執行 .py。
兩個檔案內容一致，皆可獨立使用。

## 更新與資料

請先關閉舊程式，將新版放在既有 leave_bonus_data.sqlite3 的同一資料夾。
首次升級既有資料庫前，程式會在 backups 產生完整 SQLite 備份。
保留此資料庫與 backups。新版本資料夾若沒有舊資料庫，會建立空白資料庫。
本交付包不包含個人資料庫。

## 本版修正

- 編輯日期衝突會拒絕更新，保留兩筆原紀錄。
- 資料操作及舊資料遷移採交易，出錯完整回滾。
- 舊固定表逐筆記錄遷移狀態，允許通用表已有資料；內容不同時拒絕覆蓋並提示。
- 遷移紀錄使用來源表及來源 ID，重複啟動不重複匯入。
- 升級前自動備份，資料庫版本記錄為 701。
- 驗證非負金額、有限數字、年度、每日 0～8 小時及薪資生效日年度。
- 關閉視窗時關閉資料庫連線。
- 年度詳情註明採當年度最後一筆生效薪資。

## 計算基準

沿用 V0.7 公式：1 日為 8 小時、休假滿 80 小時觸發固定補助。
保留 0 小時紀錄及小數制顯示。金額與日數仍採既有 float 計算及 Python round 顯示。
危險與留才津貼只納入月支合計，不纳入三項獎金薪資基準。
這是既有表格規則的試算工具，未另行驗證制度適用條件。

## 驗證

執行 python test_leave_bonus.py，可重跑 8 項資料與計算測試。
macOS Tkinter 四分頁建立、更新與關閉測試通過。
Windows 實機、不同 DPI、正式資料庫升級及完整互動尚待驗證。
V0.8 的出差／加班費與五分頁功能不包含於本安全修正版。
