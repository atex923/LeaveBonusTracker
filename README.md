# 休假獎金統計小本

記錄年度休假、薪水加給，試算不休假、年終與考績獎金，追蹤出差／加班費申報與入帳。
目前版本：V0.8（20261005）。Python 桌面程式，適用 Windows／macOS。

## 最新版

- [主程式 .py](LeaveBonusTracker_V0_8.py)
- [Windows .pyw](LeaveBonusTracker_V0_8.pyw)

兩檔皆可獨立執行，內容一致。

## 程式特色

- 五個分頁：年度總覽、休假登記、薪水加給、出差／加班費、資料庫說明。
- 雙月單日休假登記，已登記日期紅色標示，重複日期更正保護。
- 薪資跨年度總表，提供引入上一年度資料。
- 同年月可登錄多筆出差／加班申報，拒絕完全相同年月、送件日與金額的重複資料。
- 送件與入帳日期可由浮出日曆選擇。雙擊表格入帳日欄可直接修改或清除。
- 入帳狀態依有申報金額的項目判斷：待入帳、部分入帳、已入帳。
- 年度總覽與 UTF-8 BOM CSV 納入分項申報、已入帳、待入帳金額。
- 通用 SQLite 資料表，保留安全修正版的交易、驗證與升級前備份。
- 中上方名稱、右上角版本日期，新版淺色配色。

## 安裝與執行

需要 Python 3.10 以上及 Tkinter，無額外 pip 套件需求。

```sh
python LeaveBonusTracker_V0_8.py
```

Windows 可雙擊 .pyw。程式在自身資料夾使用 leave_bonus_data.sqlite3。
更新時先關閉舊程式，再將新版放到原資料庫同一資料夾；首次升級在 backups 建立 SQLite 備份。
請保留原資料庫及備份，交付包不包含個人資料。

薪資與獎金沿用既有表格的公式，採年度最後一筆生效薪資，1 日為 8 小時。
危險與留才津貼只納入月支合計。
出差／加班費按「申報年月」歸屬年度；入帳日代表該項申報全額入帳，未處理單一項目分批或差額付款。
費用不是獎金，合併數字標為「獎金與申報費用合計」。
年度參數與薪資引入後各自儲存，請先存年度參數再存薪資。

## 驗證與限制

14 項自動化測試通過：日期冲突、交易回滾、遷移、備份、輸入驗證、獎金門檻、CSV、申報狀態與年度統計。
macOS Tkinter 五分頁與浮出日曆跨年測試通過。
Windows 實機、DPI 縮放、正式個人資料庫升級及 Excel 開啟 CSV 尚待驗證。

執行測試：

```sh
python test_leave_bonus.py
```
